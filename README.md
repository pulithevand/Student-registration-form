# Student Registration Form

## 📌 Project Description

The **Student Registration Form** is a simple HTML5 project designed to collect student information through an HTML form.

It allows students to enter their personal details, select their gender, choose their technical skills, and provide their date of birth.

The project also includes a table displaying sample student registration details.

## 🚀 Features

- Full Name input field
- Email input field
- Password input field
- Gender selection using radio buttons
- Skills selection using checkboxes
- Date of Birth using date input
- Register button to submit the form
- Student details displayed in an HTML table

## 🛠️ Technologies Used

- HTML5

1. Clone this repository:


4. Fill in the student registration form.
